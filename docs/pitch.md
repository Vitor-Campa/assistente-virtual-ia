# Pitch - Assistente de Estudos

## Problema

Muitos estudantes possuem dificuldades para encontrar informações, entender conteúdos e organizar seus estudos.

## Solução

O Assistente de Estudos foi desenvolvido para ajudar estudantes a compreender conteúdos acadêmicos de forma simples e objetiva.

O usuário faz uma pergunta e o sistema procura uma resposta relacionada aos conteúdos disponíveis em sua base de conhecimento.

## Público-alvo

O projeto é destinado principalmente a estudantes que precisam de apoio durante os estudos.

## Tecnologias

- Python
- Inteligência Artificial
- Engenharia de Prompts
- Git
- GitHub

## Diferencial

O projeto busca apresentar conteúdos de forma simples, facilitando a compreensão de estudantes que estão começando a aprender determinados assuntos.

## Resultado

O projeto apresenta uma aplicação simples de assistente virtual, uma base de conhecimento, documentação, prompts e testes de avaliação.

## Melhorias futuras

O projeto pode receber uma integração com modelos de IA generativa, uma interface gráfica, histórico de conversas e uma base de conhecimento maior.
