# Avaliação e Métricas

## Objetivo

A avaliação foi realizada para verificar se o Assistente de Estudos consegue fornecer respostas claras e relacionadas à base de conhecimento.

## Critérios

Foram utilizados quatro critérios:

| Critério | Descrição |
|---|---|
| Clareza | A resposta é fácil de entender? |
| Relevância | A resposta está relacionada à pergunta? |
| Utilidade | A resposta ajuda o estudante? |
| Base de conhecimento | A resposta utiliza informações disponíveis? |

## Testes realizados

### Teste 1

**Pergunta:**

"Como funciona o Kanban?"

**Resultado esperado:**

Explicar que Kanban é uma forma visual de organizar tarefas.

**Resultado:**

Resposta adequada.

### Teste 2

**Pergunta:**

"O que é Python?"

**Resultado esperado:**

Explicar que Python é uma linguagem de programação.

**Resultado:**

Resposta adequada.

### Teste 3

**Pergunta:**

"O que é Scrum?"

**Resultado esperado:**

Explicar que Scrum é um framework utilizado para organizar projetos.

**Resultado:**

Resposta adequada.

### Teste 4

**Pergunta:**

"Quais são algumas dicas de estudo?"

**Resultado esperado:**

Apresentar algumas formas de organizar os estudos.

**Resultado:**

Resposta adequada.

## Resultado da avaliação

Os testes mostraram que o assistente consegue responder perguntas relacionadas aos assuntos presentes na base de conhecimento.

Como melhoria futura, a base de conhecimento pode receber mais conteúdos e o sistema pode utilizar modelos de IA reais para gerar respostas mais completas.
