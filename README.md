# assistente-virtual-ia# 🎓 Assistente de Estudos com Inteligência Artificial

## Sobre o projeto

O Assistente de Estudos é um projeto desenvolvido para o desafio **Construa Seu Assistente Virtual com Inteligência Artificial**, da DIO.

O objetivo é criar um assistente virtual capaz de ajudar estudantes durante seus estudos, fornecendo explicações simples, dicas de organização e orientações sobre conteúdos acadêmicos.

## Problema

Muitos estudantes possuem dificuldades para encontrar informações, entender determinados conteúdos e organizar seus estudos.

O assistente foi criado como uma ferramenta de apoio para facilitar esse processo.

## Solução

O Assistente de Estudos recebe uma pergunta do usuário e utiliza uma base de conhecimento para fornecer uma resposta relacionada ao assunto perguntado.

O assistente pode:

- Explicar conceitos de forma simples;
- Ajudar na revisão de conteúdos;
- Apresentar dicas de estudo;
- Responder dúvidas sobre conteúdos cadastrados;
- Fornecer exemplos para facilitar o entendimento.

## Público-alvo

O projeto é voltado principalmente para estudantes que desejam utilizar Inteligência Artificial como ferramenta de apoio aos estudos.

## Como executar

É necessário ter o Python instalado.

No terminal, dentro da pasta do projeto, execute:

```bash
python src/app.py
```

Depois, digite uma pergunta para testar o assistente.

Para encerrar o programa, digite:

```text
sair
```

## Os 6 passos do desafio

### 1. Documentação

Foi definido o objetivo do assistente, seu público-alvo e seu comportamento esperado.

### 2. Base de conhecimento

Foi criada uma base com informações sobre Engenharia de Software, metodologias ágeis, Scrum, Kanban, Python, Banco de Dados e dicas de estudo.

### 3. Prompts

Foram criadas instruções para orientar o comportamento e o estilo das respostas do assistente.

### 4. Aplicação funcional

Foi desenvolvido um programa em Python para permitir que o usuário faça perguntas e receba respostas.

### 5. Avaliação e métricas

Foram realizados testes para verificar a clareza, relevância e utilidade das respostas.

### 6. Pitch

Foi preparada uma apresentação explicando o problema, a solução e o valor do projeto.

## Resultado esperado

O projeto demonstra, de forma simples e prática, como a Inteligência Artificial pode ser utilizada como ferramenta de apoio aos estudos.
